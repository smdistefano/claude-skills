# skills

Reusable agent skills.

## architect

Read-only design review. Give it a proposed design, diff or question and it returns APPROVE, BLOCK or CLARIFY with file:line evidence. It works with any language or stack.

- `commands/architect.md`: the `/architect` command, which hands the request to the agent.
- `agents/architect.md`: the reviewer itself.
